## 대상 키워드

openssl

## 요약

총 5건의 CVE 후보를 확인했습니다. 최고 CVSS 점수는 7.5입니다.

## 주요 CVE

| CVE | 심각도 | 점수 | 설명 |
| --- | --- | ---: | --- |
| CVE-1999-0428 | UNKNOWN | 7.5 | OpenSSL and SSLeay allow remote attackers to reuse SSL sessions and bypass access controls. |
| CVE-2002-0655 | UNKNOWN | 7.5 | OpenSSL 0.9.6d and earlier, and 0.9.7-beta2 and earlier, does not properly handle ASCII representations of integers on 64 bit platforms, which could allow attackers to cause a denial of service and possibly execute arbitrary code. |
| CVE-2002-0656 | UNKNOWN | 7.5 | Buffer overflows in OpenSSL 0.9.6d and earlier, and 0.9.7-beta2 and earlier, allow remote attackers to execute arbitrary code via (1) a large client master key in SSL2 or (2) a large session ID in SSL3. |
| CVE-2000-0535 | UNKNOWN | 5.0 | OpenSSL 0.9.4 and OpenSSH for FreeBSD do not properly check for the existence of the /dev/random or /dev/urandom devices, which are absent on FreeBSD Alpha systems, which causes them to produce weak keys which may be more easily broken. |
| CVE-2001-1141 | UNKNOWN | 5.0 | The Pseudo-Random Number Generator (PRNG) in SSLeay and OpenSSL before 0.9.6b allows attackers to use the output of small PRNG requests to determine the internal state information, which could be used by attackers to predict future pseudo-random numbers. |

## 권장 조치

- 벤더 보안 공지와 패치 버전을 확인합니다.
- 노출된 서비스와 취약 버전 사용 여부를 자산 목록에서 대조합니다.
- 즉시 패치가 어렵다면 접근 제어, WAF 정책, 임시 차단 규칙을 적용합니다.
- 조치 후 재스캔하여 취약점이 해소되었는지 검증합니다.
